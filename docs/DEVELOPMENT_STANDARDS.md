# 开发规范

> 所有 Agent 必须遵循本文档规范。

---

## 📝 代码规范

### JavaScript

- 使用 ES6+ 语法
- 常量使用大写（`const CONFIG = {...}`）
- 私有方法用 `_` 前缀（`_drawLeg()`）
- 注释使用 JSDoc 格式

### Rust

- 遵循 `rustfmt` 格式
- 错误处理使用 `Result`/`Option`
- 模块导入写在文件顶部

---

## 📁 文件命名

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 动画引擎 | `animation-engine.js` | 小写+连字符 |
| 皮肤 | `skin-name.js` | 小写+连字符 |
| 动作 | 在 `index.html` 中注册 | 小写 |
| 文档 | `UPPER_CASE.md` | 大写+下划线 |

---

## 📦 目录结构

```
smellycat/
├── public/                  ← 前端代码
│   ├── index.html           ← 主入口
│   ├── pixi.min.js          ← 依赖
│   ├── anims/               ← 自定义动作（预留）
│   └── skins/               ← 自定义皮肤（预留）
│
├── src-tauri/               ← Rust 后端
├── docs/                    ← 文档
├── logs/                    ← 日志
└── temp/                    ← 临时文件
```

## 🔄 Git 提交规范

| 类型 | 说明 | 示例 |
|------|------|------|
| feat | 新功能 | `feat: 添加打哈欠动作` |
| fix | 修复 bug | `fix: 修复拖拽时位置偏移` |
| docs | 文档更新 | `docs: 添加皮肤开发指南` |
| style | 代码格式 | `style: 格式化动画引擎代码` |
| refactor | 重构 | `refactor: 分离动画引擎和皮肤` |

## ⚠️ 禁止事项

1. ❌ 不要直接修改 `pose.tail`（由物理系统处理）
2. ❌ 不要在 `update()` 中修改引擎状态
3. ❌ 不要在皮肤中使用 `save()/restore()`（PixiJS 8 不支持）
4. ❌ 不要跨 Agent 修改不属于自己职责的文件
